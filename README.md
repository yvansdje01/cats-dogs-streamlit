Le modèle déployé est un réseau de neurones convolutionnel (CNN) entraîné pour la classification binaire d’images de chats et de chiens.
L’application Streamlit permet à l’utilisateur de téléverser une image et d’obtenir instantanément une prédiction accompagnée d’un score de confiance.
L’utilisateur peut ainsi tester le modèle sur ses propres images en temps réel.
Des améliorations possibles incluent la classification multi-classes, le traitement par lots d’images et le téléchargement des résultats.
